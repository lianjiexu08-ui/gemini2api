# gemini2api 上号助手（浏览器插件）

一键把当前 Gemini 网页会话上号到 gemini2api 号池：不用再 F12 抠 Cookie。

## 安装（Chrome / Edge）

1. `chrome://extensions` → 打开右上角**开发者模式**
2. **加载已解压的扩展程序** → 选择本目录（`capture-extension/`）
3. 点浏览器工具栏里的拼图图标，把本插件**固定**到工具栏

## 配置（一次性）

点插件图标 → 填入：
- gemini2api 地址：`http://154.21.193.37:5918`
- Admin Key：面板登录 key

## 上号流程（多账号标准姿势）

> ⚠️ **核心机制**：`__Secure-1PSID` 永远属于浏览器 Profile 的**默认账号**（第一个登录的号），
> 网页右上角切头像**不会改变它**。多账号必须用隔离手段：

**方案 A：无痕窗口（插件已支持，推荐）**

1. 开一个**全新无痕窗口**（Ctrl+Shift+N），只登录**一个**目标 Google 账号
2. 打开 gemini.google.com 确认能进（**这个窗口不要关！**关了无痕 Cookie 就没了）
3. 回到正常窗口，点插件图标 → 来源选「🕶️ 无痕窗口」→ 捕获 → 确认上号
4. 下一个号：再开一个新的无痕窗口重复（每个号一个窗口，互不干扰）

**方案 B：独立 Chrome Profile（长期最省心）**

右上角头像 → 添加 → 每个车位一个 Profile，各自登录一个号，插件按 Profile 隔离。

**方案 C：清空重登法（无插件时的笨办法）**

退出 Profile 里所有 Google 账号 → 只登录目标号（它变成默认账号）→ 捕获 → 再退出换下一家。

重复账号会橙色提示；确认后可直接更新该账号的 Cookie，不会重复创建账号。

## 多账号要点

- 切换账号 = 点头像切换后**等页面刷新完**再捕获
- 如果 Seller 给的所有"车位"识别出来是同一个邮箱 → 是同一个 Google 账号，找卖家
